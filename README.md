# PetTop — Pet Shop

Loja virtual demonstrativa para pet shop, desenvolvida com React, TypeScript e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Importar na Lovable

No Lovable, escolha importar projeto existente do GitHub e selecione `luquinhachara35/pettop-petshop`.

> O projeto começa com catálogo e interações demonstrativas. Para vender de verdade, configure Supabase, pagamentos, estoque e integração de pedidos.
